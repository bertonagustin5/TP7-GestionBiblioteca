
# 📚 TP7 Integrador POO - Gestión de Biblioteca

## 📌 Descripción del proyecto

Trabajo Práctico Integrador de la asignatura **Programación Orientada a Objetos**, desarrollado en **Java** utilizando el entorno **BlueJ**.

El proyecto consiste en implementar un sistema de gestión de biblioteca que permita administrar libros, socios y préstamos.

### Funcionalidades principales

- Registrar libros y socios de la biblioteca.
- Gestionar préstamos y devoluciones de libros.
- Verificar préstamos vencidos.
- Controlar las condiciones de préstamo de estudiantes y docentes.
- Consultar qué socio tiene un determinado libro.
- Generar listados de libros, socios y docentes responsables.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Java
- **IDE:** BlueJ
- **Control de versiones:** Git y GitHub
- **Gestión de tareas:** Trello

## 🎯 Objetivo

Integrar los conocimientos adquiridos durante la asignatura mediante el desarrollo colaborativo de una aplicación orientada a objetos, respetando el diseño UML proporcionado por la cátedra.
